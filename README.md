# DRS SPA (ทาง J)

หน้า Data Request System ที่เปิดจากนอก SharePoint แล้วอ่านเขียน SharePoint list ด้วยสิทธิ์ของผู้ใช้ที่ล็อกอินเอง (MSAL, สิทธิ์ SharePoint AllSites.Write แบบผู้ใช้ยินยอมเอง)

- ตอนนี้ต่อกับไซต์ทดสอบเท่านั้น ข้อมูลสมมติ ไม่มีข้อมูลบริษัท
- หน้านี้ไม่มีข้อมูลในตัว ข้อมูลทั้งหมดอยู่ใน SharePoint ของเทนแนนต์ และผ่านสิทธิ์ของผู้ใช้คนนั้นเท่านั้น
- msal-browser.min.js คือ @azure/msal-browser 4.26.2 จาก npm (sha256 b4be707a)
